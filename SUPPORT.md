# Support

Harness Tavern is independently maintained.

## Where to ask

- Use [GitHub Discussions](https://github.com/HenryQUQ/harness-tavern/discussions) for setup questions, design discussion, and usage ideas.
- Use [GitHub Issues](https://github.com/HenryQUQ/harness-tavern/issues) for reproducible defects and scoped feature requests.
- Use [private vulnerability reporting](https://github.com/HenryQUQ/harness-tavern/security/advisories/new) for security concerns.

Before reporting a defect, run:

```bash
npm run doctor
npm run verify
```

Share the application version, operating system, Node.js version, reproduction steps, and redacted error output. Never post provider API keys, access tokens, credential key files, SQLite databases, private character data, or full prompt transcripts.

Commercial support, uptime guarantees, hosted service operation, and emergency response are not included with the MIT-licensed project.
