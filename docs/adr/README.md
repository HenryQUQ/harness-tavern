# Architecture decision records

Architecture decision records capture durable choices that constrain multiple components or future changes.

Use the next four-digit number and include:

- status and date;
- problem context;
- decision;
- consequences and rejected alternatives;
- links to affected contracts or follow-up work.

Accepted records are immutable. Superseding decisions add a new record and link both documents.
